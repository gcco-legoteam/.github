# .github

This is the [default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) repository for the [@gcco-legoteam](https://github.com/gcco-legoteam) organization on GitHub.

Files stored here are used as organization-wide defaults, applying automatically to any repository in the organization that does not have its own version of those files.

## Contents

### Issue Templates

Standardized issue templates are located in [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) and apply to all repositories in the organization.

| Template | Description |
| --- | --- |
| Bug Report | Report a bug or unexpected behaviour |
| Feature | Propose a new feature or enhancement |
| Documentation | Request or suggest documentation improvements |
| Incident | Report a live incident or outage |
| Maintenance | Track maintenance or housekeeping tasks |

## Contributing

To propose changes to these defaults, open a pull request in this repository. Changes will take effect across the organization once merged.
